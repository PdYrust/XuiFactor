# XuiFactor v0.1.0-beta

## What This Beta Includes

- Single-user and bulk traffic factor rules for 3x-ui clients.
- Pause, resume, and disable lifecycle commands with keep-result behavior.
- Daemon mode and one-shot tick execution.
- SQLite metadata tables using `xui_factor_*`.
- Config file support, doctor diagnostics, and SQLite-consistent backups.
- systemd service file and install, update, and uninstall scripts.
- Linux release packages for amd64 and arm64.

## Installation

Download the package for the server architecture, then install:

```sh
tar -xzf xui-factor_v0.1.0-beta_linux_amd64.tar.gz
cd xui-factor_v0.1.0-beta_linux_amd64
sudo ./scripts/install.sh
```

Use the `linux_arm64` package on ARM64 hosts.

## Safety Reminder

Run `xui-factor doctor` and `xui-factor backup` before broad changes. Test a single-user rule before applying bulk rules on production servers.

## Known Scope

This beta ships Linux amd64 and arm64 release packages. It does not modify 3x-ui source code.
