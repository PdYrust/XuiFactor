# XuiFactor v0.2.2-beta

## What This Patch Fixes

- Reconciles ineffective active legacy single-user rules into non-active metadata.
- Adopts or supersedes compatible legacy rules when a persistent scope already covers the same clients.
- Keeps normal `status` focused on effective active or paused rules and scopes.
- Adds `xui-factor reconcile` with `--dry-run` and `--inbound-id`.

## Installation

Download the package for the server architecture, then install:

```sh
tar -xzf xui-factor_v0.2.2-beta_linux_amd64.tar.gz
cd xui-factor_v0.2.2-beta_linux_amd64
sudo ./scripts/install.sh
```

Use the `linux_arm64` package on ARM64 hosts.

## Operator Notes

Run a dry run first on upgraded servers with older active single-user rules:

```sh
xui-factor reconcile --dry-run
xui-factor reconcile
```

Reconcile and cleanup only modify XuiFactor metadata. They do not modify 3x-ui counters.
