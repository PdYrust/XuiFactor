# XuiFactor v0.3.5-beta

## Highlights

- Hardened metadata migrations for older beta schemas before the stable release.
- Added upgrade-path coverage for single-user rules, scopes, policies, audit events, and repeated migrations.
- Polished normal `status` output around active scopes, active single-user rules, and effective factored clients.
- Added broad CLI smoke coverage across major operator commands.

## Safety

- Migration hardening only updates XuiFactor metadata tables.
- Migration does not modify `client_traffics` counters.
- Read-only commands remain read-only and do not create audit events or refresh baselines.
- Installer and package verification remain unchanged.

## Package Names

```text
xui-factor_v0.3.5-beta_linux_amd64.tar.gz
xui-factor_v0.3.5-beta_linux_arm64.tar.gz
```

## Install

```sh
tar -xzf xui-factor_v0.3.5-beta_linux_amd64.tar.gz
cd xui-factor_v0.3.5-beta_linux_amd64
sudo ./scripts/update.sh
```

Use `install.sh` instead of `update.sh` for a first install.

## Operator Checks

After upgrading, run:

```sh
xui-factor doctor
xui-factor status
xui-factor report
xui-factor reconcile --dry-run
xui-factor cleanup --dry-run
```
