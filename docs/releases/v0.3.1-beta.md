# XuiFactor v0.3.1-beta

## What Changed

- Added client exclude policies.
- Added `xui-factor exclude`, `xui-factor unexclude`, and `xui-factor excludes`.
- Excludes are stored using traffic id, inbound id, and email identity.
- Excludes win over single-user rules, inbound scopes, and global scopes.
- Status shows active exclude counts and policy lines.

## Safety

- Excluded clients receive no future factor updates while the exclude is active.
- Previously factored traffic remains unchanged.
- Removing an exclude does not retroactively factor traffic from the excluded period.
- Broad scopes remain active for other matching clients.

## Installation

Download the package for the server architecture, then install:

```sh
tar -xzf xui-factor_v0.3.1-beta_linux_amd64.tar.gz
cd xui-factor_v0.3.1-beta_linux_amd64
sudo ./scripts/install.sh
```

Use the `linux_arm64` package on ARM64 hosts.

## Operator Notes

Exclude one client from a broad scope:

```sh
xui-factor exclude --email User --inbound-id 1
xui-factor excludes
xui-factor status
```

Disable the exclude when the client should follow matching rules and scopes again:

```sh
xui-factor unexclude --email User --inbound-id 1
```
