# XuiFactor v0.2.3-beta

## What This Patch Fixes

- Normal install enables and starts `xui-factor.service` on systemd hosts.
- Normal update enables and restarts `xui-factor.service`, even if it was previously inactive.
- Service start or restart failures print direct diagnostic commands.
- `xui-factor doctor` reports service installed, enabled, and active states.
- Doctor warns when active rules or persistent scopes need the daemon but the service is not running.

## Installation

Download the package for the server architecture, then install:

```sh
tar -xzf xui-factor_v0.2.3-beta_linux_amd64.tar.gz
cd xui-factor_v0.2.3-beta_linux_amd64
sudo ./scripts/install.sh
```

Use the `linux_arm64` package on ARM64 hosts.

## Operator Notes

Install and update start the service by default. Use these flags only when another init workflow will manage the daemon:

```sh
sudo ./scripts/install.sh --no-start
sudo ./scripts/update.sh --no-restart
```

Check the service after install or update:

```sh
systemctl status xui-factor.service --no-pager
```
