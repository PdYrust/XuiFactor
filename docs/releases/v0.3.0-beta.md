# XuiFactor v0.3.0-beta

## What Changed

- Added the v0.3 policy decision foundation.
- XuiFactor now resolves one effective factor decision per client before applying tick deltas.
- Inbound persistent scopes take precedence over global persistent scopes when both match the same client.
- The internal model reserves precedence for future exclude and user override policies.
- CLI output now uses concise sectioned summaries across status, doctor, lifecycle, bulk, tick, cleanup, reconcile, and backup commands.

## Safety

- Existing single-user rules, persistent scopes, cleanup, reconciliation, and `enable-all --once` remain compatible.
- Overlapping active metadata does not double-apply factors.
- Suppressed lower-priority targets refresh baselines from current counters, so old traffic is not multiplied retroactively.
- Tick updates still use the existing compare-and-swap counter path.

## Installation

Download the package for the server architecture, then install:

```sh
tar -xzf xui-factor_v0.3.0-beta_linux_amd64.tar.gz
cd xui-factor_v0.3.0-beta_linux_amd64
sudo ./scripts/install.sh
```

Use the `linux_arm64` package on ARM64 hosts.

## Operator Notes

Run these checks after upgrading:

```sh
xui-factor doctor
xui-factor reconcile --dry-run
xui-factor status
systemctl status xui-factor.service --no-pager
```
