# XuiFactor v0.2.0-beta

## What This Beta Adds

- Persistent `enable-all` scopes for future matching clients.
- `enable-all --once` for snapshot-only bulk rules.
- Scope-aware status, pause, resume, disable, and audit behavior.
- `cleanup` command for bounded XuiFactor metadata lifecycle.
- Automatic cleanup defaults for missing clients, disabled rules/scopes, and old audit events.

## Installation

Download the package for the server architecture, then install:

```sh
tar -xzf xui-factor_v0.2.0-beta_linux_amd64.tar.gz
cd xui-factor_v0.2.0-beta_linux_amd64
sudo ./scripts/install.sh
```

Use the `linux_arm64` package on ARM64 hosts.

## Operator Notes

`enable-all` is persistent by default. Use `--once` when only current clients should be targeted.

Run `xui-factor cleanup --dry-run` before manual cleanup on production servers. Cleanup only prunes XuiFactor metadata; it does not modify 3x-ui counters. SQLite `VACUUM` runs only with `xui-factor cleanup --vacuum`.

## Safety Reminder

Run `xui-factor doctor` and `xui-factor backup` before broad changes. Test a single-user rule before applying bulk rules on production servers.
