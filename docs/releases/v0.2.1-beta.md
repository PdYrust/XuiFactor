# XuiFactor v0.2.1-beta

## What This Patch Fixes

- Consolidates compatible active single-user rules into persistent `enable-all` scopes.
- Preserves materialized client baselines and remainders during adoption.
- Marks old compatible single-user rules as merged so they stop being active effective rules.
- Keeps incompatible rules separate and records skip events for operator review.

## Installation

Download the package for the server architecture, then install:

```sh
tar -xzf xui-factor_v0.2.1-beta_linux_amd64.tar.gz
cd xui-factor_v0.2.1-beta_linux_amd64
sudo ./scripts/install.sh
```

Use the `linux_arm64` package on ARM64 hosts.

## Operator Notes

Run the same persistent bulk command again to reconcile older single-user rules:

```sh
xui-factor enable-all --inbound-id 1 --factor 2
```

Use `xui-factor status` and `xui-factor audit` to review the resulting scope and consolidation events.
