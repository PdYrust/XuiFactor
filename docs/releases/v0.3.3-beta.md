# XuiFactor v0.3.3-beta

## Highlights

- Added `xui-factor explain` for one-client effective decision inspection.
- Added `xui-factor status --effective` for grouped final policy outcomes.
- Added `xui-factor status --clients` for client-level effective factors.
- Effective views show how excludes, overrides, single-user rules, inbound scopes, and global scopes resolve.

## Safety

- Explain and effective status are read-only.
- Explain and status do not create audit events or modify 3x-ui counters.
- Effective views use the same precedence model as tick:

```text
exclude > override > single-user rule > inbound scope > global scope
```

## Package Names

```text
xui-factor_v0.3.3-beta_linux_amd64.tar.gz
xui-factor_v0.3.3-beta_linux_arm64.tar.gz
```

## Install

```sh
tar -xzf xui-factor_v0.3.3-beta_linux_amd64.tar.gz
cd xui-factor_v0.3.3-beta_linux_amd64
sudo ./scripts/update.sh
```

Use `install.sh` instead of `update.sh` for a first install.

## Examples

Explain one client:

```sh
xui-factor explain --email User --inbound-id 1
```

Show grouped effective state:

```sh
xui-factor status --effective
```

Show client-level effective factors for one inbound:

```sh
xui-factor status --clients --inbound-id 1
```
