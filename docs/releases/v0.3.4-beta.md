# XuiFactor v0.3.4-beta

## Highlights

- Added `xui-factor report` for concise policy, effective client, service, metadata, and traffic impact summaries.
- Added audit filters for event type, email, inbound, rule id, policy id, limit, and relative time windows.
- Polished audit output into the shared sectioned CLI style.
- Added forward-looking inbound and email metadata to new traffic application audit events.

## Safety

- Report and audit are read-only.
- Report and audit do not create audit events or modify 3x-ui counters.
- Traffic impact aggregates `traffic_applied` event metadata without rewriting historical events.

## Traffic Impact

Traffic impact uses audit events that include `extra_all_time` values. v0.3.4-beta adds inbound and email metadata to new traffic application events so filtered report and audit views are more precise from this release forward.

## Package Names

```text
xui-factor_v0.3.4-beta_linux_amd64.tar.gz
xui-factor_v0.3.4-beta_linux_arm64.tar.gz
```

## Install

```sh
tar -xzf xui-factor_v0.3.4-beta_linux_amd64.tar.gz
cd xui-factor_v0.3.4-beta_linux_amd64
sudo ./scripts/update.sh
```

Use `install.sh` instead of `update.sh` for a first install.

## Examples

Show a management report:

```sh
xui-factor report
xui-factor report --inbound-id 1
```

Filter audit events:

```sh
xui-factor audit --event override_enabled --limit 20
xui-factor audit --email User --inbound-id 1
xui-factor audit --since 24h
```
